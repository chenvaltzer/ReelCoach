# Privacy policy

*Last updated: November 2026*

ReelCoach is a browser extension that adds playback controls to Instagram, Facebook and TikTok videos. It is built so that it doesn't need to know anything about you.

## What ReelCoach collects

Nothing. ReelCoach has no servers, no analytics, no crash reporting, no advertising and no accounts. The developers cannot see who uses it or how.

## What is stored on your device

ReelCoach saves only your personal playback preferences, using your browser's extension storage:

| Setting | Example | Where |
|---|---|---|
| Skip seconds | `5` | Chrome sync storage |
| Shift + skip seconds | `1` | Chrome sync storage |
| Hide controls after | `2.5` | Chrome sync storage |
| Mirror on/off | `false` | Chrome sync storage |
| Extension enabled | `true` | Chrome sync storage |

If you have Chrome Sync turned on, Chrome synchronizes these settings across your signed-in devices. That is handled by Google Chrome Sync, not by ReelCoach. Removing the extension deletes these settings.

## Network requests

ReelCoach makes **zero network requests**. It runs 100% locally in your browser. It does not contact any external server, does not download files, and does not transmit data anywhere.

## What ReelCoach can see

The extension runs only on `https://www.instagram.com/`, `https://www.facebook.com/` and `https://www.tiktok.com/`. On those pages it attaches an overlay with controls (timeline, speed, skip, loop, mirror) to `<video>` elements. It does not read your messages, profile, comments, or feed history. It does not record or keep what you watch.

## Permissions

- **storage**: to remember your settings (skip duration, hide delay, mirror state, and power toggle).

No host permissions, no download permissions, no background web requests.

## Children

ReelCoach doesn't collect personal information from anyone, including children.
